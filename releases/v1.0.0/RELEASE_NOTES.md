# Release v1.0.0

Date: 2026-06-24

Contenu:
- ArenaDuel_Windows.zip — archive portable contenant l'application (Portable)
- Setup_ArenaDuel.exe — installateur Windows (Inno Setup)

Installation rapide:
- Pour une installation complète, exécuter `Setup_ArenaDuel.exe` en tant qu'administrateur.
- Pour mode portable, dézipper `ArenaDuel_Windows.zip` et lancer `ArenaDuel.exe`.

Notes:
- Ne pas committer de mises à jour binaires volumineuses fréquemment : privilégiez les GitHub Releases pour les gros fichiers.
- Signer le Setup avec un certificat PFX si vous distribuez publiquement.
